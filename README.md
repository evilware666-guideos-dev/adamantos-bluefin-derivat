# AdamantOS

Ein unzerstörbares, wartungsfreies Linux-Derivat auf Basis von **Bluefin** (GNOME/Universal Blue) – entwickelt für den deutschen Markt.

## Konzept

- **Immutable**: Das Basissystem ist schreibgeschützt und kann nicht beschädigt werden.
- **Atomare Updates**: Entweder das Update gelingt vollständig oder es rollt automatisch zurück.
- **Wartungsfrei**: Keine manuellen Eingriffe nötig – Updates kommen automatisch.
- **Deutsch**: Sprache, Tastatur und Vorlagen sind auf den deutschen Markt ausgelegt.
- **KDE/GNOME-optional**: Dieses Projekt basiert auf Bluefin (GNOME).
